# luary-cdn

Repositório público de imagens da Luary servido pelo jsDelivr.

```text
luary-cdn/
├── categories/
├── home/
├── products/
│   └── SKU/
│       ├── 01.webp
│       ├── 02.webp
│       └── ... até 10.webp
├── settings/
└── subcategorias/
```

Padrão de URL:
`https://cdn.jsdelivr.net/gh/luaryshop/luary-cdn@main/{pasta}/{arquivo}`

Produtos usam SKU em maiúsculas e nomes sequenciais `01.webp` a `10.webp`.
Não armazene segredos ou tokens neste repositório.
